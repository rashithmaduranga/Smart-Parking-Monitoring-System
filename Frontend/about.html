Project Overview & Objectives

The Smart Parking Space Monitoring and Management System with Real-Time Web Dashboard is an IoT-based solution designed to resolve campus and urban parking congestion. Utilizing high-frequency ultrasonic sensors connected to microcontrollers, the system tracks parking slot occupancy and forwards logs to a remote server.

Key Project Objectives:
  • Implement low-cost ultrasonic sensors to monitor parking slot availability with centimeter precision.
  • Facilitate real-time HTTP post-telemetry updates from ESP32 microcontrollers to Java Spring Boot REST endpoints.
  • Store and query chronological sensor logs efficiently in a MySQL relational database system.
  • Deliver a responsive web dashboard utilizing modern charts, responsive tables, and theme switches to improve the parking administration experience.
Technologies Integrated
ESP32 HC-SR04 Spring Boot MySQL HTML5 CSS3 JavaScript Bootstrap 5 Chart.js
Hardware Spec: ESP32 connects via Wi-Fi and triggers sensor distance readings every 2 seconds.
